# Frontend rules

- 기본은 Server Component로 두고, 브라우저 API·상태·이벤트가 필요한 파일에만 `use client`를 사용합니다.
- 사용자에게 보이는 버튼과 링크는 실제 동작을 연결하거나 `준비 중` 상태를 명확히 표시합니다.
- 장식용 아이콘·이모지는 보조기술에 중복해서 읽히지 않도록 처리합니다.
- 한국어 UI 문구를 바꿀 때도 오류·빈 상태·로딩 상태를 함께 확인합니다.
- 비자 요건·점수·자격 판정 문구에는 참고용 결과와 공식 확인 경로를 유지합니다.
