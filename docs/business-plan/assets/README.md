# 사업계획서 시각자료 사용 안내

모든 자료는 편집 가능한 SVG 원본과 HWP 삽입용 PNG를 함께 제공한다. 대시보드 목업은 현재 비자부기 웹의 실제 색상·카드·문구·진행 단계를 반영하고, 나머지 도표는 공모전 HWP 양식과 같은 흰 셀·검정 실선·휴먼명조 중심의 표 형식으로 구성했다. PNG는 투명 영역이 없는 완전한 흰색 배경으로 내보내 다크 모드나 한글 웹 편집기에서도 배경이 검게 보이지 않는다.

## HWP 삽입 권장값

- 가로 폭: 본문 작성 칸의 90~100%
- 배치: 글자처럼 취급
- 가로 정렬: 가운데
- 캡션: 그림 아래 9pt
- 한 페이지에 시각자료 1개와 설명 문단 1~2개만 배치
- 이미지 비율 고정을 유지하고 세로 크기를 임의로 늘리지 않음

## 표현 규칙

- 01 대시보드: 현재 웹 홈 화면의 배경색, 브랜드 색, 카드, 진행률과 단계 UI를 반영
- 02~07 도표: 흰 배경과 흰 셀, 검정 글자와 실선 테두리만 사용
- 표의 첫 열에는 비교 기준을, 이후 열에는 단계 또는 상태를 배치
- 책임 경계는 별도 색상 대신 굵은 세로선과 설명 문구로 표시

## 서체 적용

- 02~07 SVG 원본은 `휴먼명조, Nanum Myeongjo, serif` 순서로 서체를 지정해 HWP 본문 11pt의 인상을 따랐다.
- 01 대시보드는 실제 웹과 통일하기 위해 웹과 같은 산세리프 계열 서체를 사용했다.
- 현재 제작 환경에는 휴먼명조가 설치되어 있지 않아 제공 PNG에는 가장 가까운 대체 서체인 나눔명조가 적용되어 있다.
- 휴먼명조가 설치된 환경에서 SVG를 다시 PNG로 내보내면 이미지 안의 글자까지 휴먼명조로 출력할 수 있다.
- HWP 본문과 그림 캡션은 문서에서 휴먼명조를 직접 적용한다.
