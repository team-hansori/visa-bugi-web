# Data boundary rules

- `visa-data`가 소유하는 원본 PDF, 추출 CSV, 검수 전 데이터는 이 레포에 복사하지 않습니다.
- 웹앱은 검수·적재된 마스터 데이터를 조회하고, 데이터 스키마를 임의로 재정의하지 않습니다.
- `valid_from`·`valid_to`는 마스터 데이터의 유효기간입니다. 사용자의 일정·리마인더 날짜와 섞지 않습니다.
- 상대 일정은 기준 이벤트와 offset이 데이터 계약으로 확정되기 전까지 날짜를 추정하지 않습니다.
- OCR 결과에 여권번호·외국인등록번호·주소 등 개인정보가 포함될 수 있으므로 원문 장기 저장을 기본값으로 두지 않습니다.
