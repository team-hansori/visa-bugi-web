# 제13회 전국 ICT융합 공모전 사업계획서 목차 설계

## 배경

team-hansori 팀은 제13회 전국 ICT융합 공모전(2026년 지역주도 디지털혁신지원사업, 참가분야: 디지털 시제품)에
**② 충북 현안 해결 AI 혁신** 분야로 "비자부기(visa-bugi)"를 출품한다. 이 문서는 사업계획서 본문을 작성하기
전에, 공식 양식·평가기준·기존 기획 자료·실제 레포 구현 상태를 종합해 확정한 목차 설계다.

## 확정된 전제 (사용자 승인)

- **공모 분야**: ② 충북 현안 해결 AI 혁신 (노션 기획서 상단 표의 "① 도민체감형 AI 혁신" 기재는 오기이며, 실제 출전 분야는 ②로 확정)
- **서비스명**: "비자부기(visa-bugi)" 단일 명칭으로 통일. 표지 파일(`2026_사업계획서.pdf`)에 이미 작품명(사업명): 비자부기(visa-bugi), 팀장: 김태은으로 기재되어 있음. "충북살이"는 사업계획서 본문에서 사용하지 않음(노션 기획서에서는 초기 가칭으로 전반에 쓰였으나 채택하지 않음).
- **3부(기획 세부설명) 서술 방식**: Part1(서비스별 핵심 기능 및 기술 설명)은 구현 완료/개발 중 구분 없이 완성형 비전으로 서술한다. 구현 상태의 정직한 구분은 4부(실현 방안)에서 별도로 다룬다. 이는 공식 양식 자체가 3부는 "기획의 핵심내용"을, 4부는 "구현 가능성"을 요구하는 구조와 일치한다. (2026-08-28 업데이트: 아래 근거자료 §5와 같이 대부분의 핵심 기능이 실제로 구현 완료되어, 이 원칙은 이제 대부분 사실 서술과 일치한다.)
- **데이터 성숙도 비공개**: 특정 데이터셋이 mock/합성 데이터인지, 특정 기능이 환경변수로 데모 모드 전환이 가능한지 등 데이터 성숙도에 관한 세부사항은 3부·4부 어디에도 명시하지 않는다(사용자 확정, 2026-08-28). 4부의 "현재 구현 상태"는 화면·기능 단위(완료/미구현)로만 구분하고, 그 기능이 참조하는 데이터의 실제/합성 여부는 구분하지 않는다.

## 목차 설계

### 1. 요약 (표 형식, 약 1페이지)

공식 표 6개 셀(제품명/소개/사업성/가치/기대효과/관련 이미지)을 아래 내용으로 채운다.

- 제품(아이디어)명: 비자부기(visa-bugi)
- 소개: 이주노동자·유학생 대상 24시간 다국어 생활행정·체류자격 AI 게이트웨이, 4줄 요약
- 사업성: 충북 외국인 8만9,823명 중 이주노동자(2만2,259명)+유학생(1만4,303명) ≈ 41%가 실질 타깃, 지역특화형 비자(F-2-R·E-7-4R) 잠재 대상자와 겹침
- 가치: 규칙기반 계산엔진(환각 최소화) + RAG 안내 + 옵트인 이력관리, 기존 지원센터·포털을 대체하지 않고 잇는 게이트웨이 포지셔닝
- 기대효과: 충북 인구감소지역 정착 전략(지역특화형 비자) 실행 지원 + 유학생 미등록 체류 전환 감소
- 관련 이미지: 요건 충족률 대시보드 · 4단계 여정 타임라인 목업

### 2. 기획 배경

노션 기획서 1절의 논증 순서를 그대로 따른다.

1. 숫자로 보는 충북의 특수성 — 외국인 8만9,823명, 음성 18.1%·진천 13.9%(전국 2·5위)
2. 이주노동자가 겪는 구조적 문제 — 임금체불·사업장 변경 제한 등, 음성노동인권센터 사례
3. 유학생이 겪는 문제 + 충북 특수 맥락 — K-유학생 정책, 미등록 체류자 비율 11.6%
4. **결정적 연결고리** — 지역특화형 비자(F-2-R/E-7-4R/F-4-R) 요건표와 6개 인구감소지역 정착 전략의 접점 (분야 ②에 맞춘 배경 서술의 결론)
5. 충북도의 기존 대응과 한계 — 접근성·파편화·개인화 부재

### 3. 기획 세부설명

#### Part 1. 서비스별 핵심 기능 및 기술 설명

- **3-1 전체 서비스 흐름도**: 사용자 유형 확인 → 상황 발생 → AI 상황 파악(LLM 순차 질문) → 일반행정 문의 / 체류자격 점수 확인 / 위험 감지 3갈래 → 사용자 이력 저장 → 능동 리마인더. 이 흐름도 옆에 채팅 화면(모바일 스크린샷) 1장 배치.
- **3-2 핵심 기능** (표: 기능명 / 설명 / 이주노동자 시나리오 / 유학생 시나리오 + 각 기능 소개에 모바일 스크린샷 슬롯)
  1. 상황별 대화형 안내(①) — 스크린샷: 채팅 화면
  2. 공문서 촬영 → 모국어 요약(②) — 스크린샷: OCR 업로드 화면
  3. 서류 초안 작성 + 제출처 연결(③) — 스크린샷: 서식 필드 검토 화면
  4. 이력 기반 능동 리마인더(④) — 스크린샷: 캘린더 화면
  5. 위험 감지 시 대상별 전문기관 자동 연결(⑤) — 별도 스크린샷 없이 ①의 흐름도 안에서 분기로 표현
  6. 체류자격 점수·요건 트래커(⑥) — 1단계(온보딩 목표비자 추천) + 2단계(홈 대시보드 쿼터·요건배지) 2단 구성. 스크린샷: 온보딩 선택 스텝 화면 + 홈 대시보드 화면
  7. (제외) 단계별 피드백 집계 → 정책진단 데이터 전달 — 미구현 확인됨(근거자료 §5). Part1에서 다루지 않고 4부 로드맵으로 이동.
  - (참고) 지도 기반 기관 연결도 표에 추가 — 스크린샷: 지도 화면
- **3-3 핵심 기술 스택** (표: 기술 / 역할) — LLM(다국어) · OCR · RAG · 규칙 기반 자격요건 계산 엔진 · 결정론적 위험 라우팅. 규칙 기반 계산 엔진은 **visa-data의 공통 스키마 v2(13개 테이블, `visa_criterion_groups`의 AND/OR 논리 트리)와 이를 실제로 조회하는 visa-bugi-web의 6개 typed 도구(`get_visa_requirements` 등)·`buildVisaQuotaItems`를 실제 근거로 명시**해 기술적 이해도를 뒷받침한다. 위험 라우팅도 "키워드 감지"가 아니라 "`risk_routing_table`을 비자유형·지역으로 필터링하는 결정론적 라우팅"으로 정확히 서술한다.
- **3-4 안전장치 설계**: 계산 로직은 공식 고시 요건표를 구조화한 규칙 기반 엔진만 사용(LLM은 자연어→구조화 값 변환만 담당) · 요건표 정기 갱신 · 화면 내 참고용 안내 문구 상시 표시 · HITL(최종 판단은 항상 사람) 원칙
- **3-5 서비스 스코프 정의**: Tier1(체류자격 트래커·행정 서식 — 직접 구축) / Tier2(건강·직장내괴롭힘·보험 등 — 라우팅만) 구분표, 라이프사이클 4단계(추적→준비→제출→판정) 책임 경계표(충북살이 vs 하이코리아/시군담당부서/출입국사무소/법무부)

  여정(라우트 순): `/onboarding`(D-2, D-2 상세 스텝) → `/chat`("아르바이트 하고 싶어요", 허용시간·제한업종 안내) → `/ocr`(등록금 고지서 업로드) → `/documents`(서식 초안·제출현황) → `/`(홈, F-2-R 전환 요건 사전 확인)
  4단계 매핑: 추적(F-2-R 사전 확인) → 준비(신청서 초안+체크리스트) → 제출(대학 담당부서 딥링크) → 판정 미관여
  스크린샷 스트립: 온보딩 D-2 상세 스텝 → 채팅 화면 → OCR 업로드 화면 → 서식 검토 화면

각 여정은 대시보드(요건 충족률·쿼터·서류 배지)와 캘린더 카테고리(🔵체류자격/🟢학업근로/🟠생활행정/⚪기타) UI 터치포인트에 매핑해서 제시한다.

### 4. 제품(아이디어) 실현 방안

3부에서 완성형 비전으로 서술한 내용을 현실의 구현 상태와 연결하는 절 — 심사항목 "사업화"의 완성도·타당성에 대응.

1. **현재 구현 상태** (화면·기능 단위로만 구분. 데이터 성숙도는 명시하지 않음 — "확정된 전제" 참고)
   - 구현 완료: 온보딩(목표비자 추천 포함), 채팅(LLM 대화·위험 라우팅), 홈 대시보드(요건·쿼터), OCR·서식 초안, 캘린더, 지도(4개 지역), Supabase 연동, visa-data 공통 스키마 v2(13개 테이블)
   - 로드맵: 단계별 피드백 집계 → 정책진단 데이터 전달(⑦)
2. **실현 단계의 예상 문제점과 해결 방안** — 요건표 개정 시 데이터 갱신 체계(visa-data 검수 프로세스), 개인정보 리스크(원본 미저장·사본만 옵트인 보관), 정부 시스템 미연동(하이코리아 등 공개 API 부재 → 딥링크 방식으로 대체)
3. **향후 적용처 및 사업화 방안** — 1차 실증지역: 음성·진천(이주노동자) + 청주·충주(유학생 밀집 대학가), 확장 타깃: 결혼이민자·외국국적동포(F-4-R)

### 5. 기대효과 및 활용분야

- 충북에 미칠 기대(파급)효과: 인구감소지역 정착률 기여(지역특화형 비자 전환 지원), 유학생 정착 전략(K-유학생 2만 명 목표) 지원, 정책 피드백 집계를 통한 "비자 제안제" 거버넌스 연계
- 기타 활용분야: 결혼이민자·외국국적동포로의 확장, 타 광역/기초자치단체로의 이전 가능성
