# 비자부기 ICT융합 공모전 사업계획서 초안 작성 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 제13회 전국 ICT융합 공모전(분야 ② 충북 현안 해결 AI 혁신) 출품용 "비자부기(visa-bugi)" 사업계획서의 전체 본문 초안을, 확정된 목차 설계 스펙에 따라 마크다운 파일로 작성한다.

**Architecture:** 공식 hwp 양식의 5개 대목차(1.요약~5.기대효과및활용분야) 순서를 그대로 따르는 단일 마크다운 문서를 섹션별로 순차 작성한다. 각 섹션은 "내용 스펙(사실·수치·출처가 이미 확정된 불릿)"을 입력으로 받아 완결된 한국어 산문/표로 변환하고, 매 섹션마다 사실확인·용어일관성·분량 체크리스트로 검증한 뒤 커밋한다. 코드 변경이 없으므로 lint/typecheck/build는 실행하지 않는다.

**Tech Stack:** Markdown (최종적으로 사용자가 hwp 편집기에 옮겨 붙일 원고), 근거 자료는 전부 스펙 문서와 노션 기획서에서만 인용.

**Spec:** `docs/superpowers/specs/2026-08-26-ictfest-business-plan-outline-design.md`

## Global Constraints

- 서비스명은 "비자부기(visa-bugi)" 단일 표기만 사용한다. "충북살이"라는 표현은 문서 어디에도 등장하지 않는다.
- 공모 분야는 "② 충북 현안 해결 AI 혁신"으로 명시적으로 언급한다.
- 전체 분량은 15페이지 이내(공식 양식 규정), 별첨 자료 제출 불가 — 모든 이미지·표·통계는 본문 안에 포함한다.
- 모든 수치·통계·인용은 스펙 문서의 "근거 자료" 섹션에 이미 확인된 출처만 사용한다. 새로운 수치를 임의로 만들거나 추정하지 않는다. 불확실한 지점은 작성하지 않고 표시만 남긴다.
- 기관 전화번호·주소·운영시간을 적을 때는 출처와 확인일을 함께 표기한다(예: "충청북도 외국인정책추진단 043-220-2693, 2026년 8월 팜플렛 기준").
- 페르소나(응우옌 반 A, 바트 체첵)는 가상 인물이며 최초 등장 시 각주로 명시한다.
- 3부 Part1(핵심 기능 및 기술 설명)은 구현 완료/개발 중 구분 없이 완성형 비전으로 서술한다. 구현 상태의 정직한 구분은 4부에서만 다룬다. (2026-08-28: 실제로 대부분 구현 완료 상태라 이 원칙은 이제 자연스러운 사실 서술과 대부분 일치한다.)
- **데이터 성숙도는 어디에도 명시하지 않는다.** 특정 기능이 참조하는 데이터가 실제/합성인지, 환경변수로 데모 모드 전환이 가능한지 등은 Part1·4부 어디에도 쓰지 않는다(사용자 확정, 2026-08-28). 4부 "구현 상태"는 화면·기능 단위(구현완료/로드맵)로만 구분한다.
- 3부 Part1·Part2의 기능 설명·사용자 여정에는 모바일 스크린샷 슬롯을 `[스크린샷: 화면 설명]` 형식으로 표시한다. 실제 이미지 삽입은 사용자가 캡처 후 별도로 진행한다.
- 코드 변경이 아니므로 `npm run lint`/`typecheck`/`build`는 이 작업에 해당하지 않는다.

### Task 3: "2. 기획 배경" 작성

1. **숫자로 보는 충북의 특수성**
   - 충북 총인구 159만9,375명(2026년 4월 기준), 외국인 주민 8만9,823명, 도 전체 외국인 비율 5.5%
   - 음성군 18.1%(전국 시·군 중 2위), 진천군 13.9%(전국 5위)
   - 외국인 중(한국국적 미보유) 근로자 2만2,259명(최다) > 외국국적동포 1만3,320명 > 결혼이민자 5,808명 > 유학생 5,506명(2023 통계청 기준, 이 항목만 2023년임을 명시)
   - 2026년 4월 기준 유학생 수는 1만4,303명으로 전년 동기(1만537명) 대비 약 35% 증가. 국적별 베트남(30.7%)·중국(22.4%)·우즈베키스탄(20.2%)·몽골(9%)·네팔(8.1%)
   - 결론: 이주노동자(2만2,259명)+유학생(1만4,303명) ≈ 41%가 충북 외국인 정책의 실질적 다수
   - 출처: 충청북도 통계정보시스템, 충청타임즈(2026 기사), 충청도민일보·세종충청뉴스(2026.4.29 기사)

2. **이주노동자가 실제로 겪는 문제**
   - 임금체불, 최저임금 미만, 강제적립금, 산업재해, 장시간노동, 신분증 압류, 사업장 변경 제한, 폭행·폭언, 차별대우
   - 고용허가제 하 사업주 미동의 시 사업장 변경 불가라는 구조적 문제
   - 음성노동인권센터 "음성노동자권리찾기사업단" 사례(채용광고와 실제 근로계약서 불일치를 월간 노동상담 주제로 다룸)
   - 출처: 이주민과함께, 오마이뉴스(2026.6.24), 뉴스포스트(2025.9.4), 중부일보(2026.4.28), 음성노동인권센터

3. **유학생이 실제로 겪는 문제 + 충북의 특수 맥락**
   - 학사(등록·성적·장학금), 체류자격 관리(비자 갱신, 시간제취업 허가), 주거, 의료, 문화적응이 핵심 어려움
   - 충북은 유학생 유치를 지방대 생존 전략으로 삼음 — "충북형 K-유학생 정책", 2027년까지 유학생 2만 명 목표, 2026년 유학생 채용기업 채용장려금 신규 지원
   - 외국인주민 지원조례의 "90일 초과 거주 + 생계활동 종사" 요건에 유학생은 해당하지 않는 사각지대(천안시 사례로 확인된 전국적 패턴, 전북·세종은 별도 조례 제정, 충북도 2025년 도의회에 관련 조례안 발의)
   - 2024년 기준 유학생 출신 미등록 체류자 3만4,267명(2014년 6,782명 대비 5배 이상 증가), 미등록 전환 비율 2014년 7.8% → 2024년 11.6%(2022년 15.7%까지 상승). 출석률 70% 이하 연장거부, 재정능력 입증 실패, D-2→D-10 전환 후 취업처 미확보가 주요 원인
   - 출처: 대전일보(2024.3.26), 한국노동연구원 연구보고서 2025-08, 충청리뷰(2026.1.21, 김규찬 부교수 정책제언 포함), 충청북도청 보도자료

4. **결정적 연결고리 — 지역특화형 비자와 인구소멸 대응의 접점 (분야 ②에 맞춘 결론부)**
   - 충북도는 인구감소지역 6개 시군(제천·보은·옥천·영동·괴산·단양)에 외국인을 정착시키기 위해 지역특화형 비자 3종을 운영: F-2-R(우수인재, 311명 규모), E-7-4R(숙련기능인력, 542명, 비지역특화 E-7-4와 쿼터 공유), F-4-R(재외동포, 한도 없음)
